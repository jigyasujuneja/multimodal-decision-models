# Multimodal Decision Models documentation

To ship fast, calibrated structured decisions across images, UI screens, audio/video streams, retrieved documents, and agent tool calls, `multimodal-decision-models` (`v1.1.0`) decouples decision geometry and finite-sample uncertainty quantification from the underlying inference engine. You define a declarative multi-slot policy once and execute it identically across parallel masked diffusion (`/v1/systemone`), autoregressive token logprobs (`/v1/chat/completions`), frontier multimodal verifiers (`VertexGeminiBackend`), and logprob-free sampled models (`BlackBoxSampledBackend`).
